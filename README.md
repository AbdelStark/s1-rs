# s1-rs

Community project, private until launch.

Typed decisions for Rust: turn enums and structs into System One questions, and get compile-time-checked, confidence-gated answers back.

Default transport is [typesafe-rs](https://github.com/AbdelStark/typesafe-rs). Optional backend: community crate `typesafe-ai`.
